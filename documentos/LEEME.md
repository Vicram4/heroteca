# Documentos fuente

- `originales/`: copia aquí tus .doc/.ppt (o .docx/.pptx). **Nunca se modifican.**
- `convertidos/`: copias convertidas a .docx/.pptx (las genera el script).
- `extraido/`: texto, tablas e imágenes extraídos (intermedio, antes de pasar a `contenido/`).

Esta carpeta NO se sube a GitHub (ver `.gitignore`): tus documentos son privados.
